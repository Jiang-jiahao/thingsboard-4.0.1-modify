# 05-2 · 仪表盘编辑器

这一章讲怎么从零把一个仪表盘做出来：加部件、接数据、配交互。

## 进入编辑模式

打开仪表盘后点右上角的 **「编辑模式」**。工具条会换成编辑专用的一组按钮（状态/布局、添加部件、时间窗口、取消、保存）。

编辑期间的所有改动都**只在点「保存」后生效**。中途点「取消」会全部丢弃。

## 添加部件

点 **「添加部件」**，弹出部件包选择框：

![选择部件包](../images/05-dashboards/dashboard-add-widget.png)

窗口顶部有三个筛选：

| 控件 | 作用 |
|---|---|
| 搜索框 | 按部件名搜索 |
| **导入部件** | 从 JSON 导入第三方部件 |
| **部件包 / 所有部件** | 切换"按包浏览"或"平铺全部部件" |

下面一格一格的是**部件类型**的预览图。常用的几个：

| 部件 | 出现在 | 用途 |
|---|---|---|
| 图表 | 图表包 | 时序折线/柱状图，最常用 |
| 卡片 | 卡片包 | 显示单个最新值 |
| 告警部件 | 告警包 | 告警列表 |
| 表格 | 表格包 | 实体表、时序数据表 |
| 计数部件 | 计数包 | "共 N 台设备"这类统计 |
| 地图 | 地图包 | 在地图上标注设备 |
| 模拟仪表 / 控制部件 | 仪表包 | 圆形表盘、开关、旋钮 |
| 按钮 | 按钮包 | 触发动作（发 RPC、跳转） |
| 状态指示器 | 指示灯包 | 电池、信号强度条 |

点一格 → 弹出该部件的**配置对话框**。配置完点「添加」，部件就出现在仪表盘上了。

## 配数据：别名（实体别名）

部件要知道"取谁的数据"。这个"谁"不是直接写设备名，而是通过**别名（Entity Alias）**间接指定。这是仪表盘里最核心、也最容易搞混的概念。

**为什么用别名**：同一张看板要给不同客户看，硬写设备名就僵死了。用别名，部件只说"取 `目标设备` 的数据"，至于 `目标设备` 到底是哪台，由别名定义决定 —— 换一个别名定义，整张看板的数据就换了。

### 别名可以怎么定义

在仪表盘编辑态里，别名的定义方式（过滤器类型）有这些：

| 过滤器类型 | 含义 | 典型用法 |
|---|---|---|
| **状态实体** | 指"当前仪表盘选中的那个实体" | 让部件跟着顶部的实体选择器走。**最灵活** |
| **单实体** | 写死一台具体的设备/资产 | 固定看某台设备 |
| **实体列表** | 手工挑若干台 | 挑几台凑一组一起看 |
| **实体名称** | 按名称模糊匹配，如"车间" | 名字有规律时可批量取 |
| **实体类型** | 按类型取全部 | "所有设备" |
| **设备/资产/实体视图类型** | 按**档案类型**取 | "所有 MQTT 采集网关" |
| **关系查询** | 从某个实体沿关系取 | "一号厂房下面的所有设备"。见 [03-2 资产](../03-实体管理/02-资产.md#通过仪表盘按资产看数据) |
| **实体搜索查询** | 按名称+关系组合搜索 | 复杂筛选 |

> **状态实体是最值得掌握的**：用它的部件会跟随仪表盘顶部的实体选择器。客户自己切一下选择器，整屏数据就换成他那台设备的 —— 一张看板服务所有客户，不用一客户做一套。

### 部件里怎么用别名

在部件的配置对话框里，**数据源（Datasource）**一节选择前面定义好的别名：

| 字段 | 说明 |
|---|---|
| **实体别名** | 选一个别名 |
| **数据键（Data keys）** | 从该实体上取哪些键。类型分 `属性` / `时序数据` / `最新值` |
| **键的设置** | 每个键单独配：显示名（label）、颜色、单位、小数位、是否默认隐藏 |

图表部件还会多出 **Y 轴**、**图例**、**堆叠** 等设置。

### 一个部件可以接多个别名

比如"温度对比"图表可以接两个别名（车间A、车间B），每个别名下面各取 `temperature` 键，两条线画在同一张图上。

## 时间窗口

时间窗口决定图表显示哪一段数据。有三层，**就近覆盖**：

```
仪表盘默认时间窗口（编辑态里用工具条的时钟图标设置）
   └── 部件自己的时间窗口（部件配置里的"使用仪表盘时间窗口"关掉时才生效）
```

| 概念 | 说明 |
|---|---|
| **实时** | 数据持续刷新。可设"最后 N 分钟/小时/天"或"当前小时/今天"等快捷区间 |
| **历史** | 固定区间（起止时间点），适合看已过去的事件 |
| **聚合** | 数据点太密时按平均/最大/最小等聚合。**数据量大时必开**，否则图表会卡 |

> 图表看起来"只有最近一小段有数据"，通常是**时间窗口太小**（比如只有 1 小时）而设备是每 15 分钟上报一次。把窗口调大即可。

## 动作、目标与状态

部件可以做交互，形式分两类：

### 目标（State）—— 本地跳转

仪表盘可以有多个**状态**（state），本质是"同一张仪表盘里的多页"。点一个部件跳到另一个状态，就实现了"点这台设备 → 看它的详情图"。

配置位置：部件配置里的 **动作 → 打开新的仪表盘状态**，以及仪表盘编辑态的「状态」栏里定义各状态与其布局。

### 动作 —— 触发行为

| 动作类型 | 作用 |
|---|---|
| 打开新的仪表盘状态 | 同仪表盘内跳转 |
| 打开新的仪表盘 | 跳到另一个仪表盘 |
| 打开 URL | 打开外部链接 |
| 更新当前时间窗口 | 点一下就把时间窗口切成预设值 |
| 更新多个属性 / 遥测 | 向实体写入数据 |
| 发送 RPC 请求 | 向设备下发指令 |

动作可以绑在**部件整体点击**上，也可以绑在表格的**行点击**、**单元格按钮**上。

## 部件尺寸与布局

- 拖**标题栏**移动，拖**右下角**缩放。
- 网格默认 **24 列**。`sizeX` 是占几列，`sizeY` 是占几行。
- 在"布局"模式下可以设置网格的**背景色、外边距、行高**，以及 **autoFillHeight**（整页撑满视口）。

> **`autoFillHeight` 打开时，删掉一个部件，剩下的会自动长高**。看到"卡片莫名变高"就是这个原因，不是 bug。

## 保存与发布

改完点工具条的 **「保存」**。保存后：

- 只读态的展示效果立即生效（刷新页面即可看到）。
- 已经分配了客户的仪表盘，客户那边也会看到新版本。
- 想回退，只能重新改。**导出 JSON 备份是唯一可靠的版本管理手段**。
