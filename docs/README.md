# 杰能科世物联网平台 · 使用手册

本手册面向**平台的使用者**，按功能逐一介绍杰能科世物联网平台（JnksIOT，版本 4.0.1）的界面与操作。

> 本手册不含部署、运维与二次开发内容。涉及服务器安装、数据库、容器编排的说明请另见部署文档。

## 三种角色

平台按角色划分权限。你登录后能看到的菜单，取决于账号属于哪一种角色。

| 角色 | 典型账号 | 能做什么 | 侧边栏菜单项 |
|---|---|---|---|
| **系统管理员** | `sysadmin@jnks-iot.org` | 管理整个平台的租户、租户档案、平台级设置与安全策略 | 13 项 |
| **租户管理员** | `hc-admin@jnks-iot.org` | 管理本租户的设备、资产、仪表盘、规则链、客户与用户 | 21 项 |
| **客户用户** | `hd-user@jnks-iot.org` | 只看被分配给自己所属客户的设备、仪表盘与告警 | 7 项 |

**租户**（Tenant）是平台上的一个独立组织，它的数据与其他租户完全隔离。**客户**（Customer）是租户内部的下一级组织，用来把设备、资产划给不同的下游单位。

```
平台
└── 租户（一个独立组织，数据互相隔离）
    ├── 设备 / 资产 / 仪表盘 / 规则链 / 告警 …
    └── 客户（租户内部的下一级单位）
        └── 客户用户（只能看到本客户的设备）
```

角色的差别贯穿全书。凡是只有某些角色能看到的页面，章节开头都会标注出来。

## 界面通用约定

全平台的操作方式是一致的，先记住这几条，后面每一章都会用到：

- **列表页顶部工具条**：最左边的 `+` 是新建，右侧依次是刷新、搜索。部分页面在 `+` 旁还有专用按钮（如协议模板页的「HEX 测试」）。
- **表格行内动作**：每行最右侧有一排图标按钮，从左到右通常是 *分配给客户 / 复制 ID / 公开 / 管理凭证 / 删除*。图标按钮悬停会显示名称。
- **详情页**：在列表里点一行，就进入该实体的详情页。详情页顶部是一排页签（详情 / 属性 / 最新遥测数据 / 告警 / 事件 / 关联 / 审计日志…），右上角的圆形按钮进入编辑态。
- **编辑与保存**：详情页点编辑后字段才可改，改完点右下角的 ✓ 保存、✗ 取消。
- **删除确认框的按钮是「否 / 是」**，不是"删除/取消"。
- **提示条**出现在屏幕顶部的正中，短暂停留后自动消失。
- **中英混排**：个别上游遗留的字段与按钮仍是英文（例如 `Timestamp`、`Active`）。遇到英文控件按同义中文理解即可。
